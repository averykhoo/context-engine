# Orientation note

LIVING. What is true now, the next session's first steps, and facts not derivable from the code
(FRAMEWORK §5.1). The board is `context-engine task list`; this note keeps no copy of it.

The banner is written at the first clean close by `context-engine session close ...
--banner-file <banner.md> --seen none`, which puts a `## Banner (<session key>)` section before
this note's first section. Do not write that heading by hand. It holds durable lines only (the
repo's purpose, owner rules, lessons); `context-engine orient` generates the board, the asks,
the open sessions, the push state and the last close's digest, so the banner never copies them
(FRAMEWORK §5.1), and a close rewrites it only when a durable line changes.
