Specify and build US-24's triage step (owner words: US-24; ruling DEC-325, answering ASK-38 with option A).

Before raising a question to the owner:
1. If it can be decided from first principles, from the goals (charter) or from the owner's earlier decisions, get one fable subagent's opinion, then decide it as an agent decision (PROVISIONAL) that cites what it was derived from. One cheap call per question, never a fan-out (DEC-18).
2. If it is cheap to reverse and does not change the project's direction, go ahead with something reasonable even when neither the session nor fable is sure (P8 already covers this half).
3. Only what fails both tests goes to the owner, with context and a recommendation (already required by CE-44's `ask new` checks). Where the recommendation is not clear, add fable's opinion (the owner's 2026-11-09 words in US-24).
