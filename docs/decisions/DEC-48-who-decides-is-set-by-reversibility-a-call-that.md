Owner, 2026-10-15c, verbatim:

"who decides can be set by reversibility, as long as you can easily ctrl-z (without wasting too much time or tokens), opus (or fable) should be able to make the call"

Context (AGENT): said in reply to a management-theory review of the framework (session 2026-10-15c), which found that P8's "who decides" test routes by the type of decision (goals, priorities and preferences go to the owner) and never by whether it can be undone, while reversibility is applied only ad hoc (a push needs permission, a local commit does not). This widens what an agent may decide; it does not change the fable rule (DEC-18) on when a fable agent is used.
